0.1.0

  • First release: a Visual Studio-style Windows Forms designer for Rider on Linux, built on NetForms 0.1.5.
  • Design and code in two tabs (Form1.cs [Design] and Form1.cs), Toolbox, Properties with Events, Document Outline, the Format menu, Tab Order, F7 / Shift+F7.
  • Snaplines as in Visual Studio, including the magenta line for lining up text; Lock Controls and the Locked property, saved in the form's .resx; menu items can be dragged into other menus.
  • Code written exactly as Visual Studio writes it, so forms open unchanged in Visual Studio.
  • "Make This Project Work on Linux Too": one project file for Visual Studio on Windows and NetForms on Linux, with a preview and a backup. On Linux the running app uses Windows 10/11 colours, like the designer.
  • Add → Windows Form, User Control, Dialog, About Box, Login Form, Splash Screen.
  • Sharp on scaled screens; finds the .NET 10 install even when several .NETs are installed; its tool windows only appear in projects where a form has been opened in the designer.
